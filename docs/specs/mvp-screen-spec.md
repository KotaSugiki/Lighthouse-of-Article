# Lighthouse of Article MVP 画面仕様書

- ステータス: Draft
- 作成日: 2026-08-31
- 対象: MVP
- 関連ADR: [ADR-0001: MVPの対象範囲とSupabaseの採用](../adr/0001-mvp-scope-and-supabase.md)

## 1. 目的

arXivの論文をキーワードで検索し、興味のある論文を保存して、後から詳細情報・abstract・要約を確認できるWebアプリケーションのMVP画面を定義する。

MVPは個人利用を対象とする。将来のチーム利用に備え、サイドバーやデータ構造には拡張余地を残すが、チーム機能自体は実装しない。

## 2. 共通レイアウト

### デスクトップ

- 左側にサイドバーを常時表示する
- 右側のメインコンテンツに各画面を表示する
- サイドバーの選択中メニューを強調表示する

### スマートフォン

- サイドバーを折りたたむ
- メニューボタンからサイドバーを開閉する
- メインコンテンツは画面幅に合わせる
- 論文カードは1列表示にする
- タイトルやabstractは適切に折り返す

### サイドバー

MVPでは以下の2メニューを表示する。

- 論文を検索
- 保存した論文

将来の追加候補：タグ、設定、チーム、共有論文。

## 3. 論文検索画面

### 目的

キーワードを使ってarXivの論文を検索し、検索結果から論文を保存する。

### 表示要素

- キーワード入力欄
- 検索ボタン
- 検索前の案内メッセージ
- 検索結果一覧
- ページネーション

### 検索条件

- MVPではキーワード入力のみ
- カテゴリ、公開期間、著者などの詳細条件は対象外
- キーワードが空の場合は検索を実行しない
- 入力欄の近くに「キーワードを入力してください」と表示する

### 検索前

検索実行前は、検索結果を表示しない。

表示メッセージ：

> キーワードを入力して論文を検索してください

### 検索結果

- 1ページ20件
- 「前へ」「次へ」でページ移動する
- 論文カードを縦に並べる
- 検索結果の各論文には以下を表示する
  - 論文タイトル
  - 著者
  - arXiv公開日
  - abstractの一部
  - arXivへのリンク
  - 保存アイコン
  - 詳細を見る操作

### 論文カードの操作

- タイトルをクリック：論文詳細画面へ遷移
- 「詳細を見る」をクリック：論文詳細画面へ遷移
- arXivリンク：新しいタブでarXivを開く
- 保存アイコン：論文を保存、または保存を解除する
- その他のカード領域：画面遷移しない

### 保存アイコン

- 未保存：輪郭だけのブックマークアイコン
- 保存済み：塗りつぶしたブックマークアイコン
- 未保存状態のラベル：「論文を保存」
- 保存済み状態のラベル：「保存済み」または「保存を解除」
- 視覚表示だけに依存せず、ツールチップとアクセシビリティ用ラベルを付ける

### 重複保存

- arXiv論文IDを使って保存済みか判定する
- 保存済みの場合は保存アイコンを保存済み状態で表示する
- 同じ論文を重複登録しない

### 保存成功

- 保存アイコンを保存済みに変更する
- 「論文を保存しました」というトースト通知を表示する
- 検索結果画面に留まる

### 保存失敗

- 「保存に失敗しました。もう一度お試しください」というトースト通知を表示する
- 保存アイコンを未保存状態に戻す
- 検索結果画面に留まり、再試行可能にする
- 技術的な詳細は画面に表示せず、ログに記録する

### 検索中

- ローディング表示を出す
- 検索ボタンを一時的に無効化する
- 画面全体は操作可能なままにする

### 検索結果が0件

- 「該当する論文が見つかりませんでした」と表示する
- 入力したキーワードは残す
- そのまま別のキーワードで再検索できるようにする
- 代替論文やおすすめ論文は表示しない

### 検索エラー

- 「読み込みに失敗しました。時間をおいて再試行してください」と表示する
- 再試行ボタンを表示する
- 検索画面から離脱させない
- 技術的な詳細は画面に表示せず、ログに記録する

## 4. 保存論文一覧画面

### 目的

保存した論文を確認し、論文詳細画面へ移動する。

### 並び順と件数

- 保存日時の新しい順
- 1ページ20件
- 「前へ」「次へ」でページ移動する

### 論文カードの表示

- 論文タイトル
- 著者
- arXiv公開日
- 保存日時
- 要約済み／未要約
- arXivへのリンク
- 保存解除アイコンまたは操作
- 詳細を見る操作

### 操作

- タイトルまたは「詳細を見る」：論文詳細画面へ遷移
- arXivリンク：新しいタブでarXivを開く
- 保存解除：保存を解除し、成功通知を表示する

### 保存論文がない場合

- 「保存した論文はありません」と表示する
- 論文検索画面へのリンクまたはボタンを表示する
- サンプル論文は表示しない
- 初回利用ガイドはMVPでは表示しない

### 読み込み中・読み込みエラー

検索画面と同じ方針とする。

- 読み込み中はローディング表示
- エラー時は再試行ボタン
- 技術的な詳細は画面に表示しない

## 5. 論文詳細画面

### 目的

保存した論文の基本情報とabstractを確認し、arXiv閲覧や要約画面へ移動する。

### 表示要素

- 論文タイトル
- 著者一覧
- arXiv公開日
- 論文カテゴリ
- abstract全文
- 保存状態
- 保存日時
- 要約状態
  - 未要約
  - 要約済み
  - 要約処理中
  - 要約失敗
- 保存／保存解除アイコン
- 「arXivで開く」ボタン
- 「要約する」ボタン
- 保存済み要約
- 保存論文一覧へ戻る導線

### 操作

- 保存アイコン：保存／保存解除
- arXivリンク：新しいタブで開く
- 要約する：要約画面へ遷移
- 要約済みの場合：保存済み要約を表示する
- ブラウザの戻る操作でも自然に前画面へ戻れる

### 対象外

- PDFのアプリ内表示
- PDFの保存
- 論文本文全体の取得
- コメント、メモ、タグ付け
- 論文情報の編集

## 6. 要約画面

### 目的

保存済み論文のabstractをAIで要約し、結果を保存する。

### 要約元

- arXivのabstract全文のみ
- PDFや論文本文は要約対象にしない
- abstractにない内容を推測して補完しない
- 判断できない項目は「abstractからは判断できません」とする

### 表示要素

- 論文タイトル
- 著者
- abstract全文
- 要約結果
- 要約生成日時
- 使用モデル情報
- 要約状態
- 要約生成ボタン
- 論文詳細画面へ戻るリンク
- arXivで開くボタン

### 要約前

- abstractを表示する
- 「この論文を要約する」ボタンを表示する
- 未要約状態を表示する
- 保存済み論文だけ要約できるようにする

### 要約中

- 「要約を生成しています」と表示する
- ローディング表示を出す
- 要約ボタンを無効化する
- 二重実行を防止する
- 画面遷移はさせない

### 要約成功

- 構造化された要約を表示する
- 要約結果をSupabaseに保存する
- 生成日時を保存する
- 使用モデルを保存する
- 「要約を保存しました」というトースト通知を表示する
- 要約済み状態に変更する

### 要約失敗

- 「要約の生成に失敗しました。もう一度お試しください」と表示する
- 再試行ボタンを表示する
- 要約結果は保存しない
- 技術的な詳細は画面に表示せず、ログに記録する

### 要約形式

- 研究の目的
- 提案手法・アプローチ
- 主な結果
- この論文の意義
- 限界・注意点
- 3行程度の短いまとめ

## 7. 画面遷移

```text
論文検索画面
    ├─ タイトル／詳細を見る → 論文詳細画面
    ├─ 保存アイコン → 保存状態を更新
    └─ ページネーション → 検索結果のページ変更

保存論文一覧画面
    ├─ タイトル／詳細を見る → 論文詳細画面
    ├─ arXivリンク → arXiv（新しいタブ）
    ├─ 保存解除 → 保存状態を更新
    └─ ページネーション → 保存論文のページ変更

論文詳細画面
    ├─ arXivで開く → arXiv（新しいタブ）
    ├─ 要約する → 要約画面
    └─ 保存論文一覧へ戻る → 保存論文一覧画面

要約画面
    ├─ 要約生成 → 要約処理 → 要約結果表示
    ├─ arXivで開く → arXiv（新しいタブ）
    └─ 論文詳細へ戻る → 論文詳細画面
```

## 8. MVP完了条件

- キーワードでarXivを検索できる
- 検索結果を20件単位で表示できる
- 検索結果から論文を保存できる
- 同じ論文を重複保存しない
- 保存済み状態をブックマークアイコンで確認できる
- 保存論文を保存日時の新しい順で確認できる
- 保存論文を20件単位でページ移動できる
- 保存論文がない場合に検索画面へ移動できる
- 論文詳細画面でabstract全文を確認できる
- arXivを新しいタブで開ける
- abstractを使って要約を生成できる
- 要約結果を保存・再表示できる
- 読み込み中、0件、通信エラー、保存失敗、要約失敗の状態を表示できる
- PCとスマートフォンの両方で基本操作ができる
