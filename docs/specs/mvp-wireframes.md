## 1. 共通レイアウト（デスクトップ）

```text
┌─────────────────────────────────────────────────────────────┐
│ Lighthouse of Article                                      │
├──────────────────┬──────────────────────────────────────────┤
│                  │                                          │
│  🔎 論文を検索    │             メインコンテンツ              │
│  🔖 保存した論文  │                                          │
│                  │                                          │
│                  │                                          │
└──────────────────┴──────────────────────────────────────────┘
```

- 左側にサイドバーを固定表示する
- 選択中のメニューを強調表示する
- メインコンテンツはサイドバーの右側に表示する

```text
│                  │ │ キーワードを入力              │ [検索] │
│                  │ └──────────────────────────────┘         │
│                  │                                          │
│                  │   キーワードを入力して論文を検索してください │

```

### 検索結果

```text
┌──────────────────┬──────────────────────────────────────────┐
│  🔎 論文を検索    │ 論文を検索                               │
│  🔖 保存した論文  │ ┌──────────────────────────────┐         │
│                  │ │ machine learning              │ [検索] │
│                  │ └──────────────────────────────┘         │
│                  │                                          │
│                  │ ┌──────────────────────────────────────┐ │
│                  │ │ 論文タイトル                    [🔖] │ │
│                  │ │ Author A, Author B · 2026-01-01       │ │
│                  │ │ Abstractの一部...                       │ │
│                  │ │ [詳細を見る]              [arXiv ↗]   │ │
│                  │ └──────────────────────────────────────┘ │
│                  │                                          │
│                  │ ┌──────────────────────────────────────┐ │
│                  │ │ 論文タイトル                    [▱] │ │
│                  │ │ Author C · 2025-12-20                   │ │
│                  │ │ Abstractの一部...                       │ │
│                  │ │ [詳細を見る]              [arXiv ↗]   │ │
```

- 未保存アイコン：輪郭付きブックマーク

- 保存成功・失敗はトーストで通知する
- 読み込み中は検索ボタンを一時無効化する

## 6. スマートフォン表示

- サイドバーはメニューボタンから開く
- 論文カードは1列表示する
- カード内の情報は縦方向に並べる
- タイトル、abstract、ボタンは画面幅に合わせて折り返す
- ページネーションのボタンはタップしやすい大きさにする

## 7. 画面遷移

```text
検索画面 ──タイトル／詳細を見る──> 論文詳細 ──要約する──> 要約画面
   │                                  │                    │
   └──保存アイコン                     ├──arXivで開く       └──要約生成
                                      │
保存論文一覧 ──タイトル／詳細を見る──> ┘
       │
       └──arXivで開く
```
